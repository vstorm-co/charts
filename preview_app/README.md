# Preview App

A React + Vite application for previewing AI-generated charts from the `charts` library.

## Overview

This app dynamically renders chart components generated by the Python `pydantic-ai` library. When you run the playground script, it writes generated React code to `src/GeneratedComponent.jsx`, which Vite automatically hot-reloads.

## Supported Chart Types

- **Bar Chart** - For comparing categorical data
- **Pie Chart** - For showing proportions/percentages
- **Line Chart** - For trend over time (coming soon)
- **Area Chart** - For cumulative data trends (coming soon)

## Prerequisites

- Node.js 18+
- Python 3.10+
- [uv](https://docs.astral.sh/uv/) (Python package manager)

## Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Python Environment

From the root `charts` directory:

```bash
make install
```

Or manually with uv:

```bash
uv sync
```

### 3. Set Environment Variables

Copy `.env.example` to `.env` and add your OpenAI API key:

```bash
cp .env.example .env
# Edit .env with your OPENAI_API_KEY
```

## Usage

### Start the Preview App

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### Generate a Chart

In a separate terminal, run the preview_app script:

```bash
uv run python preview_app/test_chart.py
```

This will:
1. Query the AI for chart data and configuration
2. Write the generated React component to `preview_app/src/GeneratedComponent.jsx`
3. Update `preview_app/src/status.json` with render status

The preview app will automatically hot-reload the new component.

## Project Structure

```
preview_app/
├── public/              # Static assets
├── src/
│   ├── components/ui/   # Recharts wrapper components
│   │   └── chart.jsx    # Bar, Pie, Line chart wrappers
│   ├── App.jsx          # Main app with status display
│   ├── GeneratedComponent.jsx  # AI-generated code (auto-updated)
│   └── status.json      # Generation status metadata
├── index.html           # HTML entry point
└── vite.config.js       # Vite configuration
```

## Development Workflow

1. **Start the dev server**: `npm run dev`
2. **Run AI generation**: `uv run python preview_app/test_chart.py`
3. **View results**: The chart appears automatically in the browser
4. **Modify data**: Edit `preview_app/test_chart.py` and re-run

## Status Panel

The app displays a status panel showing:
- **Status**: "Waiting...", "Rendered Successfully", or error state
- **Last Update**: Timestamp of the last generation

## Troubleshooting

### Component doesn't reload after running script
- Check that `GeneratedComponent.jsx` was written successfully
- Verify Vite is running (check terminal output)
- Try manual refresh: `Cmd+R` (Mac) or `Ctrl+R` (Windows)

### Python errors
- Ensure `uv sync` was run in the root directory
- Check that `OPENAI_API_KEY` is set in `.env`
- Verify Python version >= 3.10

### Chart doesn't render
- Check browser console for syntax errors in generated code
- Ensure chart data matches the expected format (see `preview_app/test_chart.py`)
