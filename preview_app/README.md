# Preview App

A React + Vite application for previewing AI-generated charts from the `charts` library, with an interactive API server for real-time chart generation.

## Overview

This app dynamically renders chart components generated by the Python `pydantic-ai` library. It features an interactive frontend with a prompt input that communicates with a FastAPI backend to generate charts on demand.

## Supported Chart Types

- **Bar Chart** - For comparing categorical data
- **Pie Chart** - For showing proportions/percentages
- **Line Chart** - For trend over time
- **Area Chart** - For cumulative data trends

## Prerequisites

- Node.js 18+
- Python 3.10+
- [uv](https://docs.astral.sh/uv/) (Python package manager)

## Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Python Environment

From the root `charts` directory:

```bash
make install
```

Or manually with uv:

```bash
uv sync
```

### 3. Set Environment Variables

Copy `.env.example` to `.env` and add your OpenAI API key:

```bash
cp .env.example .env
# Edit .env with your OPENAI_API_KEY
```

## Usage

### Step 1: Start the Preview App

In one terminal window:

```bash
npm run dev
```

The frontend will be available at `http://localhost:5173`.

### Step 2: Start the API Server

In a separate terminal window:

```bash
uvicorn api_server:app --host 127.0.0.1 --port 8000 --reload
```

The API server will be available at `http://localhost:8000`.

### Step 3: Generate a Chart

1. Open `http://localhost:5173` in your browser
2. Type a prompt in the "Agent Prompt" input field (e.g., "Show monthly subscriptions and revenue")
3. Click "Generate" and watch the chart update in real-time

The status panel will show:

- **Status**: "Waiting...", "Generating...", "Rendered Successfully", or error state
- **Last Update**: Timestamp of the last generation

The generated chart component is written to `preview_app/src/GeneratedComponent.tsx` and hot-reloaded in the browser.

## Development Workflow

1. **Start the dev server**: `npm run dev` (frontend at <http://localhost:5173>)
2. **Start the API server**: `uvicorn api_server:app --host 127.0.0.1 --port 8000 --reload`
3. **Generate charts**: Use the prompt input in the browser to generate charts
4. **Modify data**: Edit `api_server.py` to change the data and configuration

## API Endpoints

- `GET /api/health` - Health check endpoint
- `POST /api/generate` - Generate a chart from a prompt

Request body:

```json
{
  "prompt": "Show monthly subscriptions and revenue"
}
```

Response:

```json
{
  "success": true,
  "message": "Chart generated successfully",
  "lastUpdated": "14:30:45"
}
```

## Troubleshooting

### Component doesn't reload after running script

- Check that `GeneratedComponent.tsx` was written successfully
- Verify Vite is running (check terminal output)
- Try manual refresh: `Cmd+R` (Mac) or `Ctrl+R` (Windows)

### Python errors

- Ensure `uv sync` was run in the root directory
- Check that `OPENAI_API_KEY` is set in `.env`
- Verify Python version >= 3.10

### Chart doesn't render

- Check browser console for syntax errors in generated code
- Ensure chart data matches the expected format (see `preview_app/test_chart.py`)
